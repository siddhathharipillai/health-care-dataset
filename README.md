# health-care-dataset
# Healthcare Data Analysis Using SQL and Excel

## Project Overview
This project focuses on analyzing healthcare data to understand patient information, diagnoses, laboratory test results, and health outcomes. The goal is to organize healthcare records, maintain data quality, and extract meaningful insights using SQL Server and Microsoft Excel.

## Objectives
- Organize healthcare data into structured, related tables.
- Identify missing values, duplicate records, and data inconsistencies.
- Use SQL queries to retrieve and analyze data from multiple tables.
- Apply aggregate functions to summarize patient and laboratory records.
- Explore healthcare trends through Excel summaries, tables, and visualizations.

## Tools and Technologies
- SQL Server: Database creation, table relationships, JOINs, GROUP BY, aggregate functions, and data analysis.
- Microsoft Excel: Data cleaning, validation, summaries, and visualizations.
- Python: Planned for further data analysis and automation.

#Dataset Description
The dataset is organized around the following entities:

- **Patients:** Contains patient-related information and identifiers.
- **Diagnosis:** Stores diagnosis details associated with patients.
- **Labs:** Contains laboratory test names and recorded results.
- **Outcome:** Stores available patient outcome information.

The tables are connected through relevant identifiers to support relational queries and multi-table analysis.

#Key Analysis Performed
- Retrieved healthcare records using SQL queries.
- Combined related tables using JOIN operations.
- Summarized laboratory results using AVG() and COUNT().
- Grouped records by diagnosis and test type.
- Checked data quality and organized records in Excel.
- Explored data summaries and visualizations to support interpretation.
